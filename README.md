## Project Overview
This repository contains solutions for Lab 4b focusing on:
1. Constructing a strictly typed, valid JSON dataset (`books.json`).
2. Consuming, parsing, and rendering JSON data asynchronously via the native JavaScript `fetch()` API with defensive error handling (`books.html`).
3. Transitioning native DOM operations and event handling to jQuery 4.0.0 (`jquery-dom.html`).

## Local Development & Setup Instructions
Because `books.html` uses the `fetch()` API to retrieve local resources, modern browser security (CORS) blocks direct execution via the `file://` protocol. A local development HTTP server is required.
